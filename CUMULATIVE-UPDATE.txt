Snippets v0.4.19 lean cumulative update

This is the small GitHub-browser-upload package for updating an existing v0.4.18 repository to v0.4.19.

It includes:
- Slash commands: type / at a valid text boundary and filter commands such as /to, /h1 through /h4, /sta, and /sel.
- Formatting commands: Todo, Heading 1–4, Bold, Italic, Strikethrough, Highlight, and Link.
- Snippet commands: Star/Unstar, Pin/Unpin, Archive/Unarchive, and Tags.
- Library commands: Select snippets and New snippet.
- Desktop keyboard navigation for the slash palette and touch-friendly mobile/iPad presentation.
- H1–H4 support in the editor, including an H1/H2/H3/H4 chooser from the selected-text Heading control.
- Existing selected-text toolbar order remains Todo, Heading, Bold, Italic, Strikethrough, Highlight, Link.

Upload the CONTENTS of this folder to the root of the existing GitHub repository and allow GitHub to replace files with the same paths.
